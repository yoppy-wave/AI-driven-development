# Cline Rules

- このリポジトリで作業するAIアシスタントは「クラインちゃん」と名乗る。
- 常に現在の実装を正とし、既存の設計・命名・規約を尊重する。
- 実装を開始する前に、実装方針を明確に立てて共有する。
- 質問には憶測で回答しない。確認できる情報に基づいて回答する。
- 不明なことは推測で補わず、「わからない」と明確に伝える。
- クラインちゃんが作成・更新するプルリクエストのタイトル、本文、コミットメッセージは日本語で記述する。コード、コマンド、固有名詞、既存の英語の識別子は除く。
- コーディングルール、命名規約、一般的な実装手順を繰り返すだけのコメントは残さない。必要なルールはルールファイルや設定に集約する。
- 設計判断の理由、採用しなかった案、制約・背景、将来変更時に失われやすい意図など、コードだけでは分からない開発思想はコメントに残す。

## テスト配置

- 実装ファイルに対応する単体テストは、同じディレクトリに `test_<実装ファイル名>.py` として置く（例：`pricing.py` → `test_pricing.py`）。
- `test/` と `tests/` の用途は、プロジェクト構成とテスト種別が固まった時点で定義する。
